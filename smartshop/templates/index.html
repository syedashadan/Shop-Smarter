Core DAA Implementations

Sorting & Searching Algorithms

The three foundational algorithms powering SmartShop, implemented purely by hand.

Divide & Conquer Stable

Merge Sort

Recursively divides the product array into two halves, sorts each half independently, and combines them in sorted order.

Best / Avg / Worst: O(n log n)
Auxiliary Space: O(n)
Try Merge Sort
Partition Based In-Place

Quick Sort

Chooses a pivot element and partitions the array into products cheaper and pricier than the pivot, then sorts recursively.

Best / Average: O(n log n)
Worst Case: O(n²)
Try Quick Sort
Search Algorithm Sorted Only

Binary Search

Searches target price by halving the search space on each comparison. Requires the catalog array to be sorted first.

Time Complexity: O(log n)
Space Complexity: O(1)
Try Binary Search
